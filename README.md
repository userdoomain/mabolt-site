# MABOLT | Imagem Masculina

Site institucional da **MABOLT | Imagem Masculina**, espaço premium de cuidado com a imagem masculina no Centro de Niterói/RJ.

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Sem frameworks ou dependências externas (exceto Google Fonts)
- Hospedagem: GitHub Pages

## Estrutura

```
├── index.html
├── RESEARCH.md          # Pesquisa e dados confirmados
├── ASSETS-SOURCES.md    # Fontes de imagens e assets
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── favicon.svg
```
